# Распределённые системы — вариант 54

Слияние двух распределённых отсортированных последовательностей на восьми
процессах с использованием C11 и Open MPI.

Реализовано слияние на корне с запросами целых блоков у владельцев.
Исходные блоки сохраняются, дополнительные буферы корня занимают `2N` чисел.
Обмены выполняются через `MPI_Ssend` и `MPI_Recv`.

Добавлены восемь сценариев входных данных, проверка всего результата и сохранности
входов, счётчики сообщений и трасса с модельным временем. Набор самопроверки
включает 72 распределённых запуска.

Обычный запуск выполняет прогрев и семь измерений с выводом медианы и разброса.

Условия задания и ограничения записаны в [docs/assignment.md](docs/assignment.md).
Алгоритм, протокол и оценки — в [docs/algorithm.md](docs/algorithm.md).
